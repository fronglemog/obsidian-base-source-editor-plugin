# Roadmap

The roadmap documents planned features and functionality.
This is a good place to start if you'd like to contribute to this plugin.

I intend to keep this plugin limited in scope - focused purely on the experience of editing Base files in a source-code view. All items on the roadmap are planned with this in mind.

## Editor

- [x] Search & replace
- [ ] Folding/unfolding
- [x] Render whitespace characters
- [x] Indentation guides
- [x] Font size customisation

## YAML

- [x] Theme-aware syntax highlighting
- [x] Parse formulas using Obsidian's native Base formula parser
  - [ ] Syntax analysis and validation of formulas
  - [ ] Autocompletion of formulas
  - [ ] Autocompletion/suggest file properties using vault metadata cache
- [ ] Display little red squiggles and hints if the YAML is not valid
- [ ] Autocompletion of YAML key names
- [ ] Autocompletion of values

## UX

- [ ] Add a command toolbar on mobile, similar to Obsidian's mobile toolbar for Markdown notes.
